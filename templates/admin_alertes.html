Mentions Discord (notifications)

Pour qu'une personne reçoive une vraie notification (pas juste un message dans le canal), Discord a besoin de son ID numérique, pas juste son pseudo — coller "@Slippy" dans le message ne notifie personne. Pour trouver l'ID d'un membre : Discord → Réglages utilisateur → Avancés → active "Mode développeur" → clic droit sur la personne dans la liste des membres → "Copier l'ID utilisateur" → colle-le ici.

Chaque personne choisit quels types d'alertes elle reçoit — pas juste "activé/désactivé" en bloc. Ex. : quelqu'un peut vouloir être pingé dès qu'un de ses joueurs est blessé, sans forcément vouloir être mentionné dans le résumé du lundi (ou l'inverse).

Le résumé regroupe classement, mouvement depuis une semaine, joueur le plus chaud, et un aperçu des matchs à venir (dont les back-to-backs) — un seul message groupé, pas un par joueur. Quand un ID Discord est configuré pour un pooler, chaque catégorie cochée ci-dessus le mentionne au bon moment : 📊 Résumé hebdo sur sa ligne du lundi, 🩹 Blessures dès qu'un joueur de son alignement passe blessé (déclenché quand le statut est mis à jour sur cette page ou dans Stats (admin), pas par l'actualisation automatique LNH — les statuts sont saisis à la main). Le bouton "Tester" envoie tout de suite une petite mention juste pour cette personne, peu importe ses cases cochées, pour confirmer que la notification arrive vraiment.
